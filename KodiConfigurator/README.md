## 1. Funktionsumfang

- Unterstützt bei der Erstellung aller benötigten Kodi-Instanzen
- Vereinfachte Konfiguration durch zentrale Oberfläche
- Automatische Anlage von Splitter und Device-Instanzen

## 2. Voraussetzungen

- Symcon ab Version 9.0
- Bereits eingerichteter KodiSplitter oder Discovery-Instanz

## 3. Software-Installation

Dieses Modul ist Bestandteil der [Kodi-Library](../README.md#3-software-installation).

## 4. Einrichten der Instanzen in IP-Symcon

1. Wird normalerweise automatisch von der Discovery-Instanz aufgerufen
2. Manuell anlegen über "Instanz hinzufügen" (Typ: KodiConfigurator)
3. Gewünschte Funktionen auswählen und erstellen
