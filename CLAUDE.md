# Diese Library: Kodi  

- Diese Library dient zur Anbindung von Kodi, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um Kodi-Geräte in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte bei der Erweiterung der Kodi API zu ergänzen.
- Der API von Kodi ist hier verfügbar: `https://kodi.wiki/view/JSON-RPC_API`
- Oder über `http://<your-ip>:<your-port>/jsonrpc`
